## Active Lifecycle Raw Label ETL target-state optimization

- Time: 2026-07-06 12:25 CST
- Branch:
  - `feat/raw-active-lifecycle-etl`
- Change:
  - Replaced full bid/ask book maintenance in `active-lifecycle-raw-labels` with target bid-price state.
  - Book snapshots now scan bids once and update only tracked target prices.
  - Ask levels are skipped during decode.
  - Price-change events use the replay payload `best_bid_price_micros` for strict/top-bid context and keep only target price qty paths.
  - Same-event target price changes are aggregated before path append.
